# Poster — лабораторная работа 2

Бессонов М. А., ИВТ-463. Гостевая книга: Solidity, Hardhat 3, Next.js, React, Web3.js.

## Возможности

- Подключение MetaMask через eth_requestAccounts с проверкой сети.
- Развёртывание Poster из интерфейса через MetaMask без экспорта ключа.
- Публикация текста и тега, чтение событий NewPost, адрес автора.
- Фильтр по тегам; ссылки на контракт и транзакции в Sepolia Blockscout.
- Локальная Hardhat и Ethereum Sepolia, отдельное сохранение адресов контрактов для каждой сети.

В контракте сохранён indexed tag как в методичке. Он хранится в событии как keccak256(UTF8(tag)). Интерфейс декодирует исходный тег из input транзакции post(string,string); тест проверяет соответствие хэша и исходного текста. Посты читаются пакетами по 5000 блоков от блока развёртывания. Необходимо указать точный начальный блок.

## Запуск

Нужен Node.js >=22.13 (проверено на 24.22.3). Системный Nodist на этом компьютере выбирает Node 20, поэтому можно использовать start-local.ps1, который выбирает установленный Node Codex.

Первоначальная установка: в poster-contract и poster-ui выполнить `npm ci` под Node 22.13+ и современным npm. Для старого npm на Windows может потребоваться установка optional package @nomicfoundation/edr-win32-x64-msvc.

1. В poster-contract: `npm test`, затем `npm run compile` и `node scripts/prepare-ui.mjs`.
2. Терминал 1 в poster-contract: `npm run node`.
3. Терминал 2 в poster-contract: `npm run deploy:local`, затем `node scripts/seed-local.mjs` (однократно для чистой локальной сети).
4. Терминал 3 в poster-ui: `npm run build -- --webpack`, затем `npm start`.
5. Открыть http://127.0.0.1:3000, выбрать «Локальная Hardhat» и нажать «Обновить». Отобразятся три подтверждённые локальные публикации от двух аккаунтов. Выбор тега «учёба» оставляет две.

Локальные аккаунты — общедоступные тестовые аккаунты Hardhat. Не использовать их в публичных сетях. После перезапуска локальной сети повторить развёртывание; старое Ignition-развёртывание очищается только для локальной сети по инструкции Hardhat.

## Sepolia через MetaMask

Готовый контракт: `0x5D0c4e5F9338360254AED86C5bE64D032E6077C7`, блок `12184451`, Chain ID `11155111`. Эти значения подставляются автоматически при первом открытии. Для просмотра нажать «Обновить»; подключение кошелька требуется только для записи.

Проверенный исходный код: https://eth-sepolia.blockscout.com/address/0x5D0c4e5F9338360254AED86C5bE64D032E6077C7?tab=contract

1. Выбрать Ethereum Sepolia в MetaMask и в приложении.
2. Нажать «Подключить MetaMask» и разрешить подключение.
3. Раскрыть «Создать новый контракт», нажать «Развернуть Poster» и подтвердить транзакцию в кошельке.
4. После подтверждения приложение запомнит адрес и блок. Сохранить их из полей интерфейса.
5. Заполнить текст и тег, нажать «Опубликовать», подтвердить в MetaMask.
6. Проверить список и фильтр, открыть ссылку Blockscout. Другому пользователю передать адрес контракта и блок развёртывания либо этот репозиторий с инструкцией запуска.

Также поддержан Ignition-деплой: задать локально переменную окружения SEPOLIA_PRIVATE_KEY либо использовать Hardhat keystore, затем `npm run deploy:sepolia`. Ключ не включать в код или репозиторий.

## Верификация

Создать API-ключ Etherscan в своём аккаунте и задать ETHERSCAN_API_KEY через окружение либо Hardhat keystore. В poster-contract выполнить:

```
npx hardhat verify --network sepolia АДРЕС_КОНТРАКТА
```

Конструктор без аргументов. Компилятор 0.8.30, optimizer enabled, runs=200, EVM shanghai. Исходный контракт и настройки одинаковы для браузерного и Ignition-развёртывания.
